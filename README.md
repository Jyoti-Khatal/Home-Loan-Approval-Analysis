# Home-Loan-Approval-Analysis
#Problem Statement

Financial institutions receive a large number of loan applications, making it important to evaluate applicant profiles efficiently. The goal of this project is to analyze loan applicant data to identify the key factors influencing loan approval decisions and prepare the dataset for further predictive modeling.

#Project Overview

This project focuses on performing data cleaning, exploratory data analysis (EDA), feature engineering, and data preprocessing on a home loan dataset. The analysis helps uncover patterns in applicant attributes such as income, credit history, education, and property area that influence loan approval outcomes.

# Project Workflow

1. Data Cleaning

   Handled missing values in categorical and numerical variables.

   Checked and corrected inconsistent data types.

   Ensured dataset consistency for analysis.

2. Exploratory Data Analysis (EDA)

   Analyzed distribution of applicant income and loan amount.

   Studied relationships between loan approval and applicant attributes.

   Used visualizations such as histograms, box plots, and bar charts to identify trends.

3. Feature Engineering

   Transformed categorical variables into meaningful features.

   Organized dataset structure for better analysis.

4. Data Preprocessing

   Applied categorical encoding techniques to convert non-numeric variables into numerical format.

   Standardized numerical variables for consistent scaling.

5. Data Analysis

   Used cross-tab analysis and visualizations to explore the relationship between credit history, income, education, and loan approval status.

# Key Insights

Credit history is one of the strongest factors influencing loan approval.

Applicants with higher income levels tend to have better loan approval rates.

Property area and education level also show patterns in loan approval outcomes.
